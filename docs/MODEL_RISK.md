# Model Risk Notes

This is a demonstration model, not a validated production fraud model.

Before production:
1. Establish a representative labeled dataset.
2. Define false-positive and false-negative costs.
3. Evaluate precision, recall, PR-AUC and calibration.
4. Test drift by segment and time.
5. Validate explainability and reason-code stability.
6. Establish model approval and rollback procedures.
7. Monitor outcomes and investigator feedback.
